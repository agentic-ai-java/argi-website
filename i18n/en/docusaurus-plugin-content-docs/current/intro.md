# Welcome to ARGI

ARGI stands for **Agent Runtime and Graph Intelligence** and is pronounced **"AR-jee"** (`/ˈɑːr.dʒiː/`). It provides a Java framework for building stateful agents, graph workflows, and multi-agent applications.

## Development Frameworks

We provide multiple development frameworks to help you build AI applications:

- **Agent Framework** - For building intelligent agent applications
- **Graph Core** - For building complex workflows and state management
