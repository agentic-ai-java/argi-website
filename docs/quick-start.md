# Quick Start

Use this path when starting a new Agentic AI application:

1. Choose the runtime shape.
   - Use **Agent Framework** for ReAct Agent and multi-agent applications.
   - Use **Graph Core** for explicit workflow orchestration and durable execution.
2. Pick the model adapter required by your application.
3. Add tools, memory, and human-in-the-loop policies around the agent or graph.
4. Run locally with Studio when you need visual inspection.
