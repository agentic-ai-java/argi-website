# ReAct Agent

Agentic AI provides the upper-layer ReAct Agent design for building agent and multi-agent applications in Java.

It focuses on the agent execution loop rather than provider-specific model details:

- ReAct Agent for reasoning, acting, observing, and continuing execution.
- Hooks and interceptors for context compaction, model call limits, tool control, and execution policies.
- Multi-agent patterns such as sequential, parallel, routing, loop, and supervisor collaboration.
- Human-in-the-loop support for interrupting, editing, and resuming an execution.

Use Agent Framework when your application needs a reusable agent abstraction with durable state and clear extension points.
