# Studio

Agentic AI Studio is an embedded debugging interface for agent conversations and graph workflows.

Studio helps developers inspect:

- Agent execution steps.
- Graph node transitions.
- Tool calls and intermediate outputs.
- Runtime state and checkpoint progress.

Use Studio during local development to understand why an agent made a decision, where a graph routed execution, and what state changed during a run.
